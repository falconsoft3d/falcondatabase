Claude Code

{% translate "Run this once in your terminal; Claude can then use falcondatabase in every session." %}

claude mcp add --transport http falcondatabase {{ mcp_url }} --header "Authorization: Bearer {{ ai_token }}"

Cursor · Windsurf · {% translate "other MCP clients" %}

{% blocktranslate %}Add the server to the client's MCP configuration (in Cursor, .cursor/mcp.json). In VS Code use the key "servers" and add "type": "http".{% endblocktranslate %}

{
  "mcpServers": {
    "falcondatabase": {
      "url": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer {{ ai_token }}" }
    }
  }
}

Claude Desktop

{% blocktranslate %}In Settings → Developer → Edit config (claude_desktop_config.json). It needs Node.js installed.{% endblocktranslate %}

{
  "mcpServers": {
    "falcondatabase": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ mcp_url }}", "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer {{ ai_token }}" }
    }
  }
}

{% translate "Any other AI, agent or script (HTTP)" %}

{% blocktranslate %}Each tool is also a plain endpoint: POST /api/ai/tools/<tool> with the arguments as JSON. GET /api/ai/tools returns the list with its JSON schemas, ready to declare as functions in any model.{% endblocktranslate %}

curl {{ tools_url }} -H "Authorization: Bearer {{ ai_token }}"

curl -X POST {{ tools_url }}/create_table \
  -H "Authorization: Bearer {{ ai_token }}" -H "Content-Type: application/json" \
  -d '{"project": "{% if ai_project %}{{ ai_project.ref }}{% else %}PROJECT_REF{% endif %}", "name": "tasks", "columns": [
        {"name": "title", "type": "text", "required": true},
        {"name": "done", "type": "boolean", "default": "false"}]}'
